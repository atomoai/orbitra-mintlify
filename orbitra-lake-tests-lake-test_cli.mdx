# `orbitra.lake.tests.lake.test_cli`


Unit tests for the `orbitra lake get-data` CLI command and plugin registration.

## Functions

### `capture_console`

```python
capture_console()
```


Replace the CLI console with one that captures output to a StringIO buffer.


### `run_cli`

```python
run_cli(*args)
```


Run the lake sub-app, swallowing the SystemExit(0) cyclopts raises on success.
