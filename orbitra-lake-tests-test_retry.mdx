### `TestRetryJitter`


The jitter adds up to a fraction of each wait, never waits less than the base, and is configurable.


**Methods:**

#### `test_default_jitter_adds_up_to_half_the_wait`

```python
test_default_jitter_adds_up_to_half_the_wait(self)
```

With the highest draw, the default jitter adds 50% to each wait.


#### `test_default_jitter_lower_bound_is_the_base_wait`

```python
test_default_jitter_lower_bound_is_the_base_wait(self)
```

With the lowest draw, the waits are the base ones: the jitter never shortens a wait.


#### `test_env_var_overrides_jitter`

```python
test_env_var_overrides_jitter(self, monkeypatch, value, expected)
```

ORBITRA_LAKE_RETRY_JITTER overrides the decorator's jitter argument.


#### `test_jitter_argument`

```python
test_jitter_argument(self)
```

The decorator's jitter argument sets the fraction.


#### `test_waits_spread_between_the_bounds`

```python
test_waits_spread_between_the_bounds(self)
```

Real draws land between the base wait and 1.5 times it.


#### `test_warning_includes_the_effective_wait`

```python
test_warning_includes_the_effective_wait(self)
```

Each attempt logs the wait it is about to sleep, jitter included.


### `TestRetryInvalidEnv`


An invalid retry env falls back to the decorator default with a warning instead of breaking the call.


**Methods:**

#### `test_fractional_retries_is_invalid`

```python
test_fractional_retries_is_invalid(self, monkeypatch)
```

The number of retries is an integer, so 2.5 falls back to the default.


#### `test_invalid_value_falls_back_to_the_default`

```python
test_invalid_value_falls_back_to_the_default(self, monkeypatch, name, value)
```

Each env, set to something that is not a non-negative number, warns and uses the default.


#### `test_zero_is_valid`

```python
test_zero_is_valid(self, monkeypatch)
```

Zero is a valid value: no retries, no wait, no jitter.
