# `orbitra.lake.tests.test_retry`

## Classes

### `TestRetryDecorator`


Test cases for the retry decorator function.


**Methods:**

#### `test_all_three_env_vars_override`

```python
test_all_three_env_vars_override(self, monkeypatch)
```

Setting all three env vars simultaneously overrides retries, delay, and backoff.


#### `test_default_arguments`

```python
test_default_arguments(self, monkeypatch)
```

A bare @retry uses retries=4, delay=3 and backoff=2.

#### `test_env_var_overrides_delay_and_backoff`

```python
test_env_var_overrides_delay_and_backoff(self, monkeypatch)
```

ORBITRA_LAKE_RETRY_DELAY and ORBITRA_LAKE_RETRY_BACKOFF override the decorator's timing args.


#### `test_env_var_overrides_retries`

```python
test_env_var_overrides_retries(self, monkeypatch)
```

ORBITRA_LAKE_NUMBER_OF_RETRIES overrides the decorator's retries argument.


#### `test_env_vars_default_to_decorator_args`

```python
test_env_vars_default_to_decorator_args(self, monkeypatch)
```

Without env vars, the decorator's own arguments are used.
