# `orbitra.lake.tests.lake.test_policy_models`


Tests for the ColumnMask, RowAccess and RowFilter models and their validation in TableSchemaWithPolicies.

## Classes

### `TestSerialization`


JSON round-trip, the schema_kind discriminator, and byte-for-byte compatibility of TableSchema.


**Methods:**

#### `test_access_accepts_dicts_and_row_access`

```python
test_access_accepts_dicts_and_row_access(self)
```

Test that access given as dicts and as RowAccess objects produces the same dump.


#### `test_discriminator_selects_the_class`

```python
test_discriminator_selects_the_class(self)
```

Test that AnyTableSchema parses a payload without schema_kind as TableSchema, and the subclass by its kind.


#### `test_equality_ignores_policies`

```python
test_equality_ignores_policies(self)
```

Test that __eq__ does not change: the policy diff belongs to the reconciliation.


#### `test_round_trip_is_idempotent`

```python
test_round_trip_is_idempotent(self)
```

Test that model_validate(model_dump()) returns an equal dump, in Python and in JSON.


#### `test_schema_kind_is_dumped_by_the_subclass`

```python
test_schema_kind_is_dumped_by_the_subclass(self)
```

Test that the subclass dumps schema_kind, and every mask and the row filter, None included.


#### `test_serialization_json_schema_keeps_fields`

```python
test_serialization_json_schema_keeps_fields(self)
```

Test that the serialization JSON schema (the lake API OpenAPI) lists the fields of the subclass.


#### `test_subclass_accepts_plain_columns`

```python

```

Test that ColumnSchema objects (from get_table_metadata) become columns without a mask.


#### `test_table_schema_refuses_policy_parts`

```python

```

Test that a TableSchema refuses a mask or a row filter instead of dropping it in silence.


#### `test_table_schema_serializes_as_before`

```python
test_table_schema_serializes_as_before(self)
```

Test that a TableSchema serializes byte for byte as on main: no schema_kind, no policy fields.
