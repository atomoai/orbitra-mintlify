# `orbitra.lake.tests.lake.test_pyiceberg_internal_contract`


Pins the semi-internal pyiceberg surface that PyIcebergDB composes.

The atomic write paths (ORBITRA-833/835) build single overwrite snapshots out of pyiceberg
building blocks that are not all public API. When a pyiceberg upgrade moves or reshapes one of
them, these tests fail fast with a pointer to the dependent code, instead of letting the write
path break deep inside a data flow. The behavioral suites (TestData, TestAtomicPartitionOverwrite)
remain the authority on semantics — this module only guards the import/signature surface, so keep
both in sync with `orbitra/lake/db/pyiceberg.py` when the internal usage changes.
