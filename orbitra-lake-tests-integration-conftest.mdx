### `setup_method`

```python
setup_method(request)
```


Set up the real client for one class, isolated by a table prefix and a saved query root of its own.

The class sees plain names; Unity Catalog and the raw storage hold `it_<run id>_<class>_<name>` (isolation.py).
The teardown drops every table with the class prefix and deletes the class saved query root.
