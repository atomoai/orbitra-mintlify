# `orbitra.flows.worker.environment`


The uv environment a bundle runs in: one venv per bundle, built once and reused by its runs.

## Functions

### `engine_command`

```python
engine_command(environment: ProjectEnvironment) -> str
```

### `engine_environment`

```python
engine_environment(environment: ProjectEnvironment) -> dict[str, Optional[str]]
```


Job environment overrides: ``None`` removes a variable from the engine's environment.


### `ensure_python`

```python
ensure_python(uv: str, source: Path) -> None
```


Install the Python the project pins (``.python-version``, ``requires-python``) if missing.


### `find_uv`

```python
find_uv() -> str
```
