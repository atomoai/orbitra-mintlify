# `orbitra.lake.db.unity`


The Unity Catalog backend: ``UnityDB``. Its REST transport is in ``_rest.py``, and its policy calls are in ``_policies.py``.

Return the error for a reader under an access policy outside the warehouse.


### `query_tables`

```python
query_tables(query: str, namespace: str) -> list[tuple[str, str]]
```


Return every table-like ``(namespace, name)`` pair of a DuckDB query, in order and without repeats.

CTE names are included on purpose: a CTE can have the name of a table that it reads
(``WITH t AS (SELECT * FROM t) ...``), and resolving CTE scopes is not worth the risk. A name
that is not a table answers 404 to the caller's lookup, which ignores it.

**Raises:**
- `sqlglot.errors.ParseError`: If the query does not parse.
