# `orbitra.lake.tests.lake.test_policy_reconcile`


Reconciliation of row filters and column masks in create_table, create_or_update_table and drop_table.

The Iceberg side is the local catalog; the Unity Catalog REST API is an in-memory fake.


## Functions

### `service`

```python
service(tmp_path, monkeypatch) -> Iterator[DBService]
```


A DBService on the local catalog with a fake Unity Catalog, and the namespace created.
