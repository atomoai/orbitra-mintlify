# `orbitra.lake.tests.integration.test_policy_udfs`


Evaluate the compiled UDF bodies on the Databricks SQL warehouse with the Iceberg REST spec vectors.

The bodies run as plain ``SELECT`` expressions over literals: no function, table or policy is created.


## Functions

### `remote_client`

```python
remote_client(request)
```


Build the real client. This class only runs SELECT statements, so there is nothing to clean up.


## Classes

### `TestPolicyUdfBodiesIntegration`
