# `orbitra.lake.tests.lake.test_policy_compiler`


Golden and unit tests for the pure policy compiler (no network).

## Functions

### `test_hash_column_name_is_defined_once`

```python
test_hash_column_name_is_defined_once()
```


Test that the SDK code spells the __orbitra_hash__ column name in one place: HASH_COLUMN in table_schema.py.
