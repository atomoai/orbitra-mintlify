# `orbitra.commons.secret_settings`


Resolve local secret references without recursively constructing settings.

## Functions

### `is_secret_reference`

```python
is_secret_reference(value: Any) -> bool
```


Recognize the Orbitra scheme, including malformed references to reject.


## Classes
