```python

```

Test that reconciling an unchanged schema writes nothing.

entry to the Iceberg metadata `schemas` array each time, so this asserts no growth and no
catalog write at all.

``model_validate(model_dump())``, so a non-idempotent validator would corrupt descriptions.
